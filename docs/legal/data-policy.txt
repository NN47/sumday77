Настоящая Политика объясняет, как Telegram-бот Sumday77 (далее — «Бот») обрабатывает техническую информацию о пользователях.

1. ПОЛОЖЕНИЕ ОБ ОБЕЗЛИЧЕННЫХ ДАННЫХ

1.1. Администрация Бота НЕ осуществляет сбор, запись, хранение и обработку персональных данных, позволяющих идентифицировать личность Пользователя (таких как фамилия, имя, отчество, номер телефона, паспортные данные, адрес или Email).

1.2. Все данные, сохраняемые в базе данных (уникальный цифровой идентификатор Telegram ID, подтверждение достижения возраста 18 лет, вес, пол, уровень активности, количество шагов, миллилитры воды и записи о съеденных продуктах), являются ПОЛНОСТЬЮ ОБЕЗЛИЧЕННЫМИ ТЕХНИЧЕСКИМИ ДАННЫМИ. По ним невозможно установить личность конкретного человека без прямого доступа к серверам мессенджера Telegram, которым Администрация не обладает.

1.3. На основании обезличенного характера данных к архитектуре Бота не применяются требования ч. 5 ст. 18 Закона РФ № 152-ФЗ «О персональных данных» в части обязательной локализации баз данных строго на территории РФ. Серверное оборудование Бота легально находится на территории Финляндии.

2. ЦЕЛЬ СБОРА ДАННЫХ И ПЕРЕДАЧА ТРЕТЬИМ ЛИЦАМ

2.1. Данные обрабатываются для обеспечения работы аккаунта и функций Бота; автоматического расчёта КБЖУ; ведения дневников питания, воды, веса и физической активности, а также структурированных заметок с оценкой дня и выбранными факторами; анализа рациона и формирования индивидуальной фитнес-статистики; отправки настроенных Пользователем напоминаний и уведомлений; обработки обращений в поддержку; фиксации версии и времени принятия Пользовательского соглашения, ознакомления с настоящей Политикой и подтверждения возрастного ограничения; применения тарифов, квот и технических ограничений; обеспечения безопасности, диагностики ошибок и стабильности сервиса; а также внутренней служебной аналитики использования Бота. Данные не используются для рекламного профилирования.

2.2. При отправке текстовых запросов и изображений (фотографий продуктов питания, этикеток) в сторонние API (OpenAI / DeepSeek / Google Gemini / Яндекс ИИ) для их распознавания и анализа технические данные, необходимые для выполнения соответствующей функции Бота (текст состава блюда, структурированная оценка дня и выбранные факторы, переданные медиафайлы), обрабатываются указанными сервисами.

Администрация не осуществляет намеренную передачу сторонним ИИ-провайдерам идентифицирующих данных Пользователя, таких как Telegram ID, имя пользователя, номер телефона и иных сведений, не требующихся для выполнения соответствующей функции Бота.

В случае использования зарубежных провайдеров (OpenAI, DeepSeek, Google Gemini) передаваемые технические данные могут использоваться ими для улучшения качества работы их систем и обучения моделей искусственного интеллекта. Пользователь обязан использовать поля ввода Бота строго по целевому назначению.

Отмечая пункт «Ознакомлен», Пользователь подтверждает, что прочитал настоящую Политику и понимает описанный порядок обработки данных. Эта отметка сама по себе не является отдельным согласием на обработку персональных данных.

2.3. Данные пользователей никогда не продаются и не передаются рекламным компаниям.

3. БЕЗОПАСНОСТЬ И УДАЛЕНИЕ ДАННЫХ

3.1. Данные хранятся в защищённой базе данных на арендованном сервере в Финляндии. Доступ к базе данных из внешнего интернета закрыт средствами сети Docker и межсетевого экрана (firewall). Бот не сохраняет фотографии в основной базе данных и постоянном файловом хранилище приложения. Фотографии временно обрабатываются для анализа и передаются AI-провайдерам. Отсутствие постоянного хранения фотографий самим Ботом не означает их удаления из Telegram или систем AI-провайдеров.

3.2. Пользователь вправе в любой момент прекратить использование Бота и запросить удаление своего аккаунта и связанных с ним записей из основной базы данных Бота.

3.3. Удаление аккаунта осуществляется с помощью кнопки «🗑 Удалить аккаунт» в настройках Бота после выполнения предусмотренных подтверждений либо через обращение в поддержку. При успешном завершении удаления записи аккаунта и связанные с ним данные удаляются из основной базы данных Бота. Если удаление через кнопку недоступно или завершилось ошибкой, Пользователь может обратиться к Администрации: {support_contact}.
