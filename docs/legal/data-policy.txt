Настоящая Политика объясняет, как Telegram-бот Sumday77 (далее — «Бот») обрабатывает техническую информацию о пользователях.

1. ПОЛОЖЕНИЕ ОБ ОБЕЗЛИЧЕННЫХ ДАННЫХ

1.1. Администрация Бота НЕ осуществляет сбор, запись, хранение и обработку персональных данных, позволяющих идентифицировать личность Пользователя (таких как фамилия, имя, отчество, номер телефона, паспортные данные, адрес или Email).

1.2. Все данные, сохраняемые в базе данных (уникальный цифровой идентификатор Telegram ID, указанный возраст, вес, пол, уровень активности, количество шагов, миллилитры воды и записи о съеденных продуктах), являются ПОЛНОСТЬЮ ОБЕЗЛИЧЕННЫМИ ТЕХНИЧЕСКИМИ ДАННЫМИ. По ним невозможно установить личность конкретного человека без прямого доступа к серверам мессенджера Telegram, которым Администрация не обладает.

1.3. На основании обезличенного характера данных к архитектуре Бота не применяются требования ч. 5 ст. 18.1 Закона РФ № 152-ФЗ «О персональных данных» в части обязательной локализации баз данных строго на территории РФ. Серверное оборудование Бота легально находится на территории Финляндии.

2. ЦЕЛЬ СБОРА ДАННЫХ И ПЕРЕДАЧА ТРЕТЬИМ ЛИЦАМ

2.1. Все данные собираются исключительно для автоматического расчёта КБЖУ, анализа вашего рациона и вывода индивидуальной фитнес-статистики в интерфейс Бота.

2.2. При отправке текстовых запросов и изображений (фотографий продуктов питания, этикеток) в сторонние API (OpenAI / DeepSeek / Google Gemini / Яндекс ИИ) для их распознавания и анализа, технические анонимизированные данные (текст состава блюда, параметры тегов самочувствия, переданные медиафайлы) обрабатываются указанными сервисами. Передача прямой личной информации (имен, телефонов, паспортов) Пользователя Администрацией полностью исключена. В случае использования зарубежных провайдеров (OpenAI, Google Gemini) анонимизированные технические данные могут быть использованы ими для улучшения качества работы их систем и обучения моделей искусственного интеллекта. Пользователь, принимая условия сервиса, соглашается с такой обработкой и обязан использовать поля ввода Бота строго по целевому назначению.

2.3. Данные пользователей никогда не продаются и не передаются рекламным компаниям.

3. БЕЗОПАСНОСТЬ И УДАЛЕНИЕ ДАННЫХ

3.1. Данные хранятся в защищённой базе данных на арендованном сервере в Финляндии. Доступ к базе данных из внешнего интернета закрыт средствами сети Docker и межсетевого экрана (firewall). Бот не сохраняет фотографии в основной базе данных и постоянном файловом хранилище приложения. Фотографии временно обрабатываются для анализа и передаются AI-провайдерам. Отсутствие постоянного хранения фотографий самим Ботом не означает их удаления из Telegram или систем AI-провайдеров.

3.2. Пользователь вправе в любой момент прекратить использование Бота и запросить удаление своего аккаунта и связанных с ним записей из основной базы данных Бота.

3.3. Удаление аккаунта осуществляется с помощью кнопки «🗑 Удалить аккаунт» в настройках Бота после выполнения предусмотренных подтверждений либо через обращение в поддержку. При успешном завершении удаления записи аккаунта и связанные с ним данные удаляются из основной базы данных Бота. Если удаление через кнопку недоступно или завершилось ошибкой, Пользователь может обратиться к Администрации: {support_contact}.
